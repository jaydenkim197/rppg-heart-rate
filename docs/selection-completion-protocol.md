## 공개 개발 순서

1. 공식 STAPLE 배포본의 표준 실행, 레거시 런타임 의존성과 MEX 재구성 가능성을 확인한다. 호환 환경이나 공식 동작을 보존한 대체를 확보 못하면 그 시도와 함께 이번 Windows MATLAB 비교에서 제외하고, 성능은 미평가로 남긴다.
2. 적격 추적 후보를 채택한다. ROI 재검출은 합성 이동·가림·재등장으로 따로 검증한다. 보이는 프레임의 ROI 위치, 가린 프레임의 오탐, 재등장 뒤 지연, 검색 범위 밖 실패를 기록한다. 실제 영상의 프레임별 정답은 별도 자료로 확보해야 한다.
3. 채택한 추적에서 포화 정책, Butterworth 등 시간 필터, FFT 길이, 윈도우 함수를 앞 순서대로 적용한다. 앞 결정값이 일치하는 기존 개발 비교는 재사용한다. 피크 후보를 다시 비교한다. Method B 공간 필터와 Method C 색상 보정은 각 방법만 바꾸고 공통 설정과 분석 창을 유지한다. Method D는 POS 창, SQI, ROI Fusion 차례로 앞 단계의 선택을 전달한다.
4. 기본 공간 커널에서 통과 후보가 없는 경우 Median, Mean, Gaussian, Wiener의 5×5 커널을 같은 28명, 지표, 최소 기준으로 한 번 추가 점검한다. Bilateral의 기존 커널을 유지한다. 두 크기에서 모두 통과 후보가 없으면 B 설정 고정을 보류한다.
5. 추적×포화, 시간 필터×FFT, SQI×Fusion 상호작용은 등록 순위와 상위 후보로 확인한다. 후행 설정까지 담은 조합에서 통과 여부도 확인한다. 통과하지 못하는 조합의 낮은 MAE만으로 순차 결정을 덮어쓰지 않는다.

주 비교의 적격점수 차이가 0.02 이내인 후보는 후보별 추가 창 `[30,60)`, `[30,45)`, `[45,60)`에서만 동점 보완을 한다. 추적은 0초에 시작하고 중간에 초기화하지 않는다. 주 비교와 같은 기준 생성, 실패 유지, 가중치 및 표본 하한을 적용한다. 너무 짧은 영상의 창은 실패 행으로 남긴다. 추가 비교에서 최소 조건을 통과한 후보 사이에 0.02를 넘는 차이가 있을 때 해당 결과를 사용한다. 보완 결과로도 동점이거나 판정 근거가 부족하면 원 비교의 적격 동점 집합에 속한 기존 설정을 유지한다. 기존 설정이 동점 집합 밖이면 다음 순서를 적용한다. 공간 필터 기본 순서는 기존 Median 이후 Mean, Gaussian, Bilateral, Wiener이며 크기가 같을 때 해당한다.

## 코드와 평가의 고정

- Method A~D와 기본 pooled POS 각각의 유효 설정, ROI 좌표 규약, 코드 Git SHA, 실행 응용 프로그램 버전을 기록한다. 각 방법의 최종 조합이 개발 기준을 충족하지 않으면 해당 상태를 명시한다. 최소 조건을 충족한 최종 설정을 잠그기 전에 독립과 자체 추정 성능을 열지 않는다.
- UBFC 독립 평가는 기존 14명 분할과 개발과 동일한 `[0,30)` 및 15초 양쪽 창, 접촉 PPG 검증, 첫 표시 프레임의 Cascade 초기화를 사용한다. 소표본 최소 기준은 유효 30초 기준 9명, 30초 예측·기준 쌍 8명, 유효 변화 기준 7명이다. MAE ≤15 BPM, 피험자 내 오차 SD RMS ≤12 BPM, ΔBPM MAE ≤12 BPM, 유효 추정률 ≥85%, ±10 BPM 이내 ≥50%, 기준 변화 쌍에서 유효 추정 ≥70%의 수치 기준은 유지한다. 표본 미달 또는 성능 미달은 별도로 기록한다. 독립 결과는 평가 후에도 설정 조정에 사용할 수 없다.
- 자체 평가는 기본 거리별 영상 54개의 원본 표시 방향과 PTS, 시작점부터의 반개구간 `[0,60)`, 같은 창의 Apple Watch 기준을 사용한다. 네 방법으로 216회 시도하고 pooled POS 54회는 별도 대조로 계산한다. 추정률에는 모든 해당 영상이 들어간다. 기준 측정이 있는 실패도 ±5·±10 BPM 이내 비율의 분모에 들어간다. 오차 지표에는 추정과 기준 쌍이 있는 사례만 들어간다.
- 거리별 방법 통과 기준은 예정된 9개 시도 중 유효 추정 ≥8, 기준과 유효 추정 쌍 ≥8, MAE ≤15 BPM, 기준이 있는 전체 시도에서 ±10 BPM 이내 ≥50%다. 0.5m부터 연속으로 통과한 마지막 거리를 최대 측정 가능 거리로 보고한다. 중간 거리 미달 뒤 통과한 거리도 별도로 표시한다. 0.5m가 미달이면 범위에서 입증한 최대 거리가 없다.
- Method D의 pooled POS 대비 차이는 동일 영상의 유효한 추정·기준 쌍에서 절대 오차 차이, 양쪽의 유효률과 성공·실패 비대칭으로 보고한다. 피험자 3명, 반복 촬영을 고려해 피험자별·거리별 결과를 곁들이고 생리적 개선으로 일반화하지 않는다.
- 초기화는 추정·기준 BPM을 보기 전 첫 표시 프레임에서 실행한다. UBFC의 기본 MATLAB Cascade와 최대 면적 선택을 우선한다. 자체 촬영에서 자동 ROI를 만들 수 없는 경우 승인된 로컬 작업자가 첫 프레임 표시 좌표에서 등록한 ROI를 사용하고 초기화 방법을 기록할 수 있다. 추정 실패 후의 ROI 재등록은 허용하지 않는다.
- Apple Watch의 불규칙 표본 간격과 관측 지연을 기록하며, 안정 거리 영상에서 프레임 수준 기준이나 생리 지연의 정답을 추정하지 않는다. 움직임과 운동 뒤 회복 평가는 자료 확보 시 별도로 실행한다.
