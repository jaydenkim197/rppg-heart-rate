# UBFC 접촉 PPG 참조 확정 및 검증

## 실험 전 등록

UBFC Dataset 2 제공자는 CMS50E 접촉 산소포화도계의 파형과 기기 심박을 함께 제공한다. 제작팀은 기기 심박에 이상치가 관찰된 점과 접촉 파형 비교의 중요성을 보고했다. 공개 개발 28명에서만 아래 규칙의 적용률과 민감도를 조사한다. 독립 14명과 자체 촬영 파일은 이 과정에서 보존한다. [UBFC 배포자 안내](https://sites.google.com/view/ybenezeth/ubfcrppg) · [제작팀 실험 설명](https://link.springer.com/article/10.1186/s12938-018-0450-3)

- 절대 오차 참조는 `[0,30)`초, 변화량 참조는 `[0,15)`와 `[15,30)`초다. 구간은 제공된 접촉 PPG 시각을 사용한다. 두 15초 창이 모두 수용된 피험자만 ΔBPM과 방향 일치의 참조가 있다.
- 기존 `estimate_ubfc_reference`에서 양쪽 경계를 포함해 1/3초 이하인 관측 공백, 5초 이상인 관측 폭, 평균 관측률 6 Hz 초과를 요구한다. 1/3초는 탐색 대역 상한 3 Hz 한 주기다. 접촉 PPG에 재표본화와 공백 채움은 적용하지 않는다.
- 선형 추세 제거 후 Lomb–Scargle의 0.7–3.0 Hz 최대 피크를 주 참조 후보로 사용한다. 대역 에너지 비율과 평탄 신호 검사를 유지한다. 최대 피크 ±0.10 Hz의 대역 내 에너지 비율 0.25 이상은 분산된 스펙트럼을 걸러내는 공학적 보수 기준이다. [MathWorks Lomb–Scargle](https://www.mathworks.com/help/signal/ref/plomb.html)
- 별도 검사는 2초 이동 중앙값을 뺀 PPG에서 최대점을 검출한다. 10~90 분위 진폭 범위의 0.30배를 최소 돌출도로 두고, 인접 피크는 3 Hz의 한 주기 이상 떨어져야 한다. 0.7–3.0 Hz에 해당하는 실제 박동 간격의 중앙값을 BPM으로 변환한다. 유효 간격 네 개 이상과 평가 구간의 70% 이상을 덮는 유효 간격을 요구한다. 이 검사는 독립 시간영역 확인용이다. [PPG 박동 검출 비교 연구](https://doi.org/10.1088/1361-6579/ac826d)
- 두 파형 추정값의 차이가 5 BPM 이하여야 주 참조를 수용한다. 5 BPM은 과제의 심박 오차 비교 규모에 맞춘 실용 기준이다. 같은 파형을 두 방식으로 확인하므로 공통 왜곡과 절대 시계 차이의 검증은 남는다. 기기가 표시한 심박은 별도 진단 열로 유지한다. 결측·모호한 창의 `gt_bpm`은 NaN이며 실패 사유와 두 추정값을 기록한다.
- 민감도 점검에는 합의 한계 3/8 BPM과 ±0.1초 경계 이동을 사용한다. 음수 시각을 피하도록 이동 점검은 `[0.1,29.9)` 기준에 ±0.1초를 적용하며, 영상과 시계를 재정렬하는 데 쓰지 않는다. 사전 등록한 최소 참조 수는 30초 유효 18명과 15초 유효 쌍 12명이다. 미달 시 공식 후보 비교를 보류한다.
